# Healthcare Operations Performance Dashboard

## Overview
Enterprise analytics platform built for a 6-department hospital network 
to replace manual Excel reporting with automated, real-time KPI dashboards 
using SQL, Python, and Tableau.

## Problem Solved
Leadership relied on manual Excel reports that took 3 days to compile. 
This project automated the entire pipeline and delivered same-day visibility 
into 12 operational KPIs.

## Tools & Technologies
- SQL (CTEs, Window Functions, Aggregations)
- Python (Pandas, NumPy) — data cleaning & validation
- Tableau — interactive KPI dashboard
- Excel — statistical summaries & reporting

## Key Results
- 120,000+ patient records validated with 99% data accuracy
- Reduced reporting turnaround from 3 days to same-day
- 12 KPIs tracked: bed occupancy, wait times, staff utilization, readmission rates
- Estimated 15% reduction in overtime costs through staffing insights

## Project Structure
- /data — raw and cleaned datasets
- /sql — SQL queries for data extraction and analysis
- /python — data cleaning and validation scripts
- /dashboard — Tableau workbook files
- /reports — Excel statistical summaries
